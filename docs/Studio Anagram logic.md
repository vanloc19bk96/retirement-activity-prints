# Retirement Activity Prints – Anagram Game Spec

## Template
- key: `retirement-anagram`
- category: `word`
- producesAnswerKey: true
- 1 puzzle page + 1 automatic answer key
- Target: Adults / Retirees / Seniors
- Print-first, large-print friendly, B&W, KDP safe area.

## Goal
Player rearranges scrambled letters to form retirement-related words.

Example:
TRAVEL → VELTRA
GARDEN → DENGAR
PENSION → SIONPEN

Do NOT reuse the generic Anagram theme library from Memory Activity Prints.

---

## Config

### `topic`
Select:
- Retirement Life
- Travel & Vacations
- Hobbies & Leisure
- Gardening
- Family & Grandchildren
- Health & Wellness
- Relaxation
- Bucket List
- Volunteering
- Home & Lifestyle
- Memories & Nostalgia
- Custom Topic

Default: `Retirement Life`

### `customTopic`
- Visible when topic = Custom Topic
- max 120 chars

### `itemCount`
- default: 12
- min: 8
- max: 20

### `difficulty`
- Easy: 4–6 letters
- Medium: 5–8 letters
- Hard: 7–11 letters

Default: Medium

### Shared
Use existing Studio settings:
- title
- fontFamily
- seed
- page size
- etc.

## AI Content Generation

ALL puzzle words must be generated by AI.
Do NOT use bundled/curated retirement word lists.

Send backend:

{
  topic,
  itemCount,
  difficulty,
  seed,
  avoid
}

Ask AI for `itemCount + 5` candidates.

AI rules:
- Words must clearly relate to the selected retirement topic.
- Familiar English vocabulary suitable for adults/seniors.
- A–Z letters only.
- Single words only.
- No proper nouns.
- No brands.
- No abbreviations.
- No offensive/depressing retirement concepts.
- No duplicates.
- Follow difficulty word-length limits.
- Prefer words with only one common anagram solution.

Normalize → validate → deduplicate → unique-anagram filter → select itemCount.

If AI cannot return enough valid words:
retry AI once with a different variety instruction.
Do NOT fall back to generic animals/common-theme words.

---

## Scramble Logic

Reuse existing `scrambleWord()` logic.

Requirements:
- scrambled letters must be exact permutation of answer.
- scrambled !== answer.
- deterministic from seed.
- Hard difficulty should prefer derangement.
- Never change/add/remove letters.

---

## Puzzle Layout

Title:
`Retirement Anagrams`
or
`Unscramble: {Topic}`

Instruction:
`Unscramble the letters to reveal each retirement-themed word.`

Two-column table:

| Scrambled Word | Your Answer |
|----------------|-------------|
| VELTRA          | __________ |
| DENGAR          | __________ |

- Large readable font.
- Number each item.
- One scramble per line.
- No hints.
- Keep entire table inside Studio/KDP safe area.
- Automatically shrink/recenter grid when itemCount increases.

---

## Answer Key

Generate automatically using same items/order.

| Scrambled Word | Answer |
|----------------|--------|
| VELTRA          | TRAVEL |
| DENGAR          | GARDEN |

- Black answer ink.
- No writing lines.
- No instructions required on answer page.

---

## Variety

Use:
`studioVarietyKey('retirement-anagram', topic, difficulty)`

Remember recently generated answers and send them in `avoid`
so consecutive pages/books do not repeatedly generate the same words.

---

## Validation / Tests

Must verify:
- exact requested itemCount
- answer follows difficulty length
- scramble is permutation of answer
- scramble !== answer
- no duplicate answers
- no duplicated scrambled words
- no overflow outside safe area
- 20-item layout fits
- puzzle and answer key match exactly
- same seed = same puzzle
- different seed should produce different content/order when possible
